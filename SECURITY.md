# Security

This repository holds the plugin package only: a manifest, the address of the hosted server, a skill and an icon. It runs no code. Anything that could be a vulnerability lives in the service at spendpoint.ai.

Report a security problem to support@spendpoint.ai. The service's disclosure statement is at https://spendpoint.ai/.well-known/security.txt, which names a key at https://spendpoint.ai/pgp-key.txt for reports you would rather encrypt, and its policy at https://spendpoint.ai/support. Please do not open a public issue for a security report.
